# 📚 Study Assistant

An AI-powered Study Assistant built using Python, Streamlit and Ollama.

## ✨ Features

- 🤖 AI Chatbot
- 🎭 Multiple personalities
- 📄 Upload study notes
- 💬 Ask questions from notes
- 🎨 Simple customized UI

## 🛠️ Technologies

- Python
- Streamlit
- Ollama
- Llama 3.2

🔨 Currently under development.
